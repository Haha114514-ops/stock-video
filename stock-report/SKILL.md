# stock-report —— 个股图文报告

> 规约版本：2026-11-09 初版。读表方法、数据口径、红线全部沿用 stock-video（`<video>/SKILL.md` 第 1~3 步与红线、`<video>/方法与口径.md`），本文件只写"成品换成图文报告后哪里不一样"。两个 skill 可以同时装，互不影响；同一期可以先出报告再出视频，`data/`、`材料摘录.md`、`facts.py`、`故事.md` 共用。

## 目标

和视频一样：**替懒得看报表的普通投资者把表读了，讲清楚这家公司现在怎么样、为什么会这样；再回答为什么这么便宜（或这么贵）、是不是真便宜、什么情况下就不成立——每一句都站得住，并且愿意从头读到尾。**

视频的效果在纸面上怎么对应：

| 视频 | 报告 |
|---|---|
| 一章 = 一个绘制函数，讲到什么才出现什么 | 一章 = 报告稿的一个 `##`；图紧跟在讲它的那一段后面，没讲到的表不提前放 |
| 强调 = 被讲到的元素亮起来，其余压暗 | 每张图 `focus=` 点名这段在讲的那一块，其余自动压暗、亮的加细边；正文 `==重点==` 金色 |
| 章节进度条、片头条 | 每章顶上一条章节进度条（当前章金色）；封面 = 片头（主线 + 公司一句话 + 三张数字卡） |
| 旁白念数字，照 facts 的说法 | 正文数字写成 `{{键|规格}}` 从 facts 取；数字卡下自动印 facts 冻结的说法 |
| 金句卡、推测、推算念出前提 | `::: 金句`（全篇两三次）、`::: 推测`（几种可能并列）、`::: 推算`（前提写全）三种框 |
| 结尾念免责声明 | 文末和每页页脚自动印"不构成投资建议"；参考价图自动印"非目标价" |
| 暗色画面 | 默认暗色（深底金字，和视频一个样子）；`--theme paper` 出白底打印版 |

读者和观众的一个区别：**报告读者会跳着看**。所以加一页**摘要**（故事.md 第五节"该带走的几句话"，按成文核过），放在封面后；结论在摘要和结尾各说一次，正文里不重复。

## 0. 分工

照 stock-video 第 0 步：主控只做判断（冻结 facts、写 故事.md 和报告稿、读审稿结果、交付），读材料和做图交给子代理；任务书 `templates/子代理任务书.md`。

| 角色 | 什么时候 | 做什么 | 交回 |
|---|---|---|---|
| **主控** | 全程 | facts.py、故事.md、报告稿.md、交付（中途不停下来等用户确认） | — |
| **材料员**（执行档） | 第 1 步 | 同 stock-video 任务书第一节 | `材料摘录.md` |
| **口径审员**（判断档） | 第 3 步报告稿交排版员前；第 6 步复核改过的段落 | 本任务书第二节 | 逐条意见 |
| **排版员**（执行档） | 报告稿过了 report_check 和口径审片后 | charts.py → build_report → 看页面 → 改 | PDF + 300 字以内 |

主控的规矩照 stock-video 第 0 步（开工新开会话只做这一期、一期一个工程目录、开头只读规约和模板、看 facts 只用 `facts_peek.py`、不亲自写 charts.py、返工继续同一个子代理）。

## 1~2. 拉数据、读材料、冻结"数 + 说法"、读表找原因

**完全照 stock-video 第 1、2 步做**，脚本和模板都用它的：

```
python <video>/scripts/fetch_data.py <代码> <工程>/data --no-numbers     # 年报 / 半年报 + 切段（起材料员）
python <video>/scripts/fetch_data.py <代码> <工程>/data --no-reports     # 数字
python <video>/scripts/fetch_hk.py  <代码> <工程>/data                   # 港股
python <video>/scripts/facts_peek.py <工程> [键前缀…]                     # 看 facts
```

- `facts.py` 里 `from rlib import put, pct_stats, window_1y`（`<report>/scripts/rlib.py`，和 stock-video `components.py` 同一写法、同一份 facts.json 格式；不会带起视频引擎）。数和说法一起冻结，推算的说法写全前提，未经审计的带"未经审计"。
- **报告里要放进图的数也冻结进 facts**：瀑布图每 100 元的各刀、资产负债表两根柱的各段、现金桥各项、估值序列和分位——charts.py 只从 facts 取。
- 把 `<video>/templates/故事模板.md` 复制成 `<工程>/故事.md` 按顺序填：⓪ 这门生意、① 三张表各两拍（总览 + 深挖）、命门、② 管理层兑现检查、③ 估值推理表、④ 看情况要讲的、⑤ 主线和章节。口径看 `<video>/方法与口径.md` 用到的那节。

## 3. 写报告稿，过检查（不等用户确认）

- 把 `templates/报告稿模板.md` 复制成 `<工程>/报告稿.md`。文件头写公司 / 代码 / 截止日 / 主线 / 公司一句话 / **三表总览落在哪三张图** / 封面卡。
- 章节照 故事.md 第六节；**每章的骨架就是视频的一章**：开场的问题 → 生意 + 利润表 → 资产负债表 → 现金流量表 → 管理层 → 估值三问（一条推理，写在同一章）→ 什么情况下不成立、接下来看什么。可以按主线调顺序，三张表一张不能少。
- 写法照视频旁白的要求，换成书面：用问题推进；数字翻成人话（"每卖 100 块，落下 4 块"）；第一次出现的术语半句白话；一个数写一遍；推算写"推算"和前提；推测写"推测 / 可能"、并列几种；未经审计第一次出现时说出来。**不注水**：逐段问"删掉这段，读者少知道什么"。段落短，一段一个意思；一章 1~3 张图。
- 每张图在稿里写成 `[[图 函数名]]`，紧跟在讲它的那段后面；段落在讲哪一块，就在交给排版员时写清 focus 对准哪一块（可写在图名上一行的 `<!-- focus: 所得税 -->` 注释里，注释不印）。
- **写完先跑** `python <report>/scripts/report_check.py <工程>` → `report_check.txt`。"必须改"清零（文件头、`{{键}}` 找不到、三表总览没写或资产负债表总览不是两根柱、红线、未经审计没先说），"要核"逐条看过。
- **再过口径审片**（任务书第二节），采纳了哪些、没采纳的理由写进 故事.md 第七节改稿记录。原来要用户拍板的事主控按"拿不准就不写、写就标来源"自己定，交付时列给用户。

## 4. 做图（排版员）

把 `templates/charts_skeleton.py` 复制成 `<工程>/charts.py`，报告稿里每个 `[[图 名字]]` 一个同名函数，参数是 facts，返回 fig。`from rcharts import *` 提供（画法照 方法与口径 §0 §2）：

| 函数 | 用在 |
|---|---|
| `waterfall` | 利润表总览：每 100 元收入被哪几刀切走，落到归母（金色） |
| `bs_two_bars` | 资产负债表总览：同一时点"有什么""钱是谁的"两根柱 + 右侧读数卡 |
| `cash_bridge` | 现金流量表总览：年初现金 → 经营 / 投资 / 筹资 → 年末 |
| `seg_share` | 业务构成：收入占比 vs 毛利占比 + 毛利率 |
| `bars` / `lines` / `hbars` | 多年对比（净利润 vs 经营现金流等）、比率走势、排名 / 测试结果 |
| `val_grid` | 估值四宫格（PB、PE × 长期 / 近 5 年，分位带 + 现值点；亏损写"PE 不适用"） |
| `price_line` | 近一年股价 + 只算利润的参考价（自动标"非目标价"） |

画图原则照 stock-video 第 4 步：结论要有证据（说"几乎没负债"就把负债拆出来）；一张图一件事；颜色有含义（涨红跌绿，红绿表示对利润好坏时有图例，金色 = 重点 / 当前值）；示意图标"示意"；坐标从 0 起（比率、价格、对数轴例外要写明）；口径写在图角（`note=`）。不够用就在 charts.py 里直接用 matplotlib 另画，配色用 `C('gold')` 等。

## 5. 出 PDF

```
python <report>/scripts/build_report.py <工程>                 # → output/报告.html + 报告.pdf（暗色）
python <report>/scripts/build_report.py <工程> --theme paper   # 白底打印版
python <report>/scripts/build_report.py <工程> --html-only     # 只出 HTML（没有浏览器时，用浏览器打开后"打印 → 存为 PDF"）
```

看页面：`pdftoppm -r 50 -png output/报告.pdf output/p` 或直接打开 PDF。看：图有没有被切开、某页是不是只剩一两行、图里亮的是不是正文在讲的那块、角注有没有。

## 6. 验收

- 主控读排版员的消息和 `report_check.txt`（改过稿就重跑），抽看三张表总览那三页和估值那页。
- 口径审片之后又改过的段落，交给同一个口径审员按前五问只核这些段落。
- 交付：PDF 路径 + 页数 + 主线一句话 + 主控代为决定的事 + 摘要那几句 + 口径与推断说明（哪些自算、哪些推断、哪些来自媒体或未经审计）。

## 红线

照 stock-video 的五条，一条不少：数字可溯源、说法跟着数字走；不编造；免责声明（build_report 自动印，正文结尾也写）；改数字 facts → 正文 → 图三处同步（正文用 `{{键}}`、图从 FX 取就自动同步）；不给个性化买卖建议，参考价不是目标价。

## 改这份规约的方法

照 stock-video"改这份规约的方法"。两边都有的规矩（读表、口径、红线）只改 stock-video 那份，这里引用；只跟图文成品有关的（版式、图表函数、report_check）改这里。

## 已知坑

- PDF 用本机 Chrome / Edge / playwright 的 chromium（`STOCK_VIDEO_BROWSER` 可指定）。页边底色和页码用 CSS `@page` 的页边框，要 Chrome 131 以上；更老的浏览器页边是白的、没有页码，内容不受影响。
- 图表字体：先用 stock-video 的 `sysenv.py`（macOS 苹方 / Windows 雅黑 / Linux 思源），找不到再问 fontconfig；都没有就设 `STOCK_VIDEO_FONT_R`。
- 某些中文字体没有"−"（U+2212），图上的负号用普通减号。
- facts 里存的是元；正文写亿元时用 `{{键|亿}}`。手写的亿元数 report_check 也会按 ÷1e8 去对。
