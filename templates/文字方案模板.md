## 五、口径审片（交画面员前，子代理做）

> 另起口径审员（`templates/子代理任务书.md` 第二节），只给 `data/`、`facts.json`、`facts.md`、本文件、`plan_check.txt`（不给 故事.md；facts 用 `facts_peek.py` 看，`data/` 按需查，不整份读）。它逐条回答下面七问；作者在每条下面写"已改 / 不改 + 理由"。口径审片之后旁白再改的句子（画面员报上来要改字、主控自己改），改完当场、render 之前交回同一个子代理按第 1~5、7 问只核改动句，并加查两件：采纳的意见，同一类在别处改全了没有；这轮改动有没有带进新的前后矛盾。

1. 旁白里每个数念出来的说法（时间窗、对象、口径），和 facts.json 的 `labels` / data/ 一致吗？
2. 公告类事实（牌照、协议、股东安排）对照 `quotes` 原文：有没有漏掉条件、例外，或改写成原文没有的意思？
3. 推算句：前提念全了吗（已扣什么、没算什么）？截止日之后已发生的支出扣了吗？分镜里的图角注和旁白是同一个前提吗？用部分期间推全年的，看过各季度分布吗（`facts.md` 单季拆分）？算派息能否持续时，这家公司的刚性支出（租赁付款等）扣了没有、说了没有？
4. 有没有说过头：单一归因、把"市场在定价什么"说成事实、像目标价或买卖建议、核心论据未经审计却没说？"连续""首次""通常""拐点""比……多 / 少"算过吗、方向对吗？
5. 结论和片中推算矛盾吗（例如把片子自己算出已在发生的事说成"如果发生才不便宜"）？
6. 命门漏了吗：`材料摘录.md` 第 0 节的每条线索（钱压得最多的科目、公司自己报的经营指标、审计师点名的、分析师反复问的），片子里交代了没有？没交代的，文字方案里有没有写不讲的理由？一个懂这行的人看完，最可能问"怎么没讲 X"的 X 是什么？
7. 口径前后一致吗：放在一起比的几个变化（股价跌幅、利润降幅、倍数变化）从同一时点算吗？股价涨跌写明含不含分红了吗？同比是同月末对同月末吗（经营数据也算）？"近一年"是往回 365 天吗？总览的判断标准在开场、估值、结尾、"接下来看什么"里是不是同一句话、同一个门槛？画面上出现的同行，旁白都提到了吗？
